# Abstract

This lane solves a finite-horizon adversarial source-coding problem in which a categorical source law moves by at most a declared total-variation distance per period while the encoder uses either one static zero-error prefix code or a precommitted code sequence. Changing period costs destroy the separability available to a fixed code. The full path is therefore optimized as one rational polytope, with an exact sparse LP dual certificate. A two-state construction shows a strict gap between independently robustifying each time marginal and respecting temporal consistency. A three-state prefix-code construction shows that a planned code rotation can outperform every static code because a bounded-mobility source cannot immediately redirect probability toward each new long-codeword state. An explicit switching penalty produces an exact reconfiguration phase boundary. The results are internal finite coding theorems and do not constitute evidence for simulation or claims about an unknown parent substrate.
