# Coupled-drift nonclaims

The coupled-drift lane does **not** establish any of the following without
additional assumptions and models.

1. That a real-world source law follows a bounded-TV path.
2. That a statistical confidence region remains valid under arbitrary drift.
3. That a source adversary observes or reacts to the selected codebook.
4. That a precommitted code sequence is an adaptive feedback policy.
5. That the independent marginal relaxation is achievable.
6. That common cost ordering is necessary for marginal equality.
7. That expected prefix length determines peak bandwidth or queue delay.
8. That codebook switching costs physical energy equal to the abstract penalty.
9. That an LP dual multiplier is a physical force, entropy, or energy.
10. That an exact bounded active-set checker scales to large alphabets or long
    horizons.
11. That total variation is the correct temporal geometry for every physical or
    computational architecture.
12. That a decision-theoretic threshold is a thermodynamic phase transition.
13. That internal communication costs reveal parent-universe hardware costs.
14. That temporal compatibility or code reconfiguration is evidence for a
    simulation hypothesis.
15. That rejecting one restricted dynamic renderer rejects all possible
    simulators.

These boundaries are part of the result rather than caveats added afterward.
