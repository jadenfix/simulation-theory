# Coupled-drift nonclaims

The coupled-drift lane proves exact finite optimization statements only for its declared source-coding interface.

It does not claim:

- that an observed physical system has a probability law available to a renderer;
- that total variation is the correct metric for every physical or epistemic transition;
- that source drift is adversarial in nature;
- that a hypothetical simulator uses binary prefix codes;
- that internal expected message length equals external memory, energy, mass, latency, or spacetime volume;
- that changing a representation is physically free when the switching penalty is set to zero;
- that precommitted code sequences are equivalent to adaptive policies;
- that periodwise confidence regions compose into a valid pathwise confidence sequence;
- that an exact optimization theorem supplies empirical evidence for simulation.

The scientific use of this lane is narrower: it identifies how temporal consistency and decision timing alter the minimum internal predictive or communication state under an explicit model.
