# Coupled-drift review checklist

- [ ] Source-law path and code-decision timing are explicit.
- [ ] Every rational search cap is reported.
- [ ] Temporal TV constraints are checked between consecutive laws.
- [ ] Marginal envelope is labeled an upper bound.
- [ ] Exact dual stationarity and complementary slackness replay.
- [ ] Switching penalty is separated from expected code length.
- [ ] Open-loop results are not called adaptive.
- [ ] Internal bits are not called parent hardware.
- [ ] No optimization result is presented as evidence for simulation.
