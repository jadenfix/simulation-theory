# Coupled-drift research frontier

The coupled finite-horizon lane separates four decision timings that must not be conflated:

1. **Static commitment** — one codebook is fixed for the full horizon.
2. **Open-loop sequence** — a full codebook sequence is fixed before the source path.
3. **State-feedback control** — the next codebook may depend on an observed source-law state or sufficient statistic.
4. **Partial-observation control** — the next codebook depends only on a declared filtration generated by samples, messages, or delayed measurements.

Only the first two are solved in the current branch. The next mathematically defensible extension is a finite dynamic game with an explicit information pattern.

## Candidate next theorem

For finite source-law state set `Q`, finite code set `C`, transition correspondence `Gamma(q,c)` and stage cost

\[
q^\top\ell_c+\kappa(c_{t-1},c),
\]

a fully observed minimax policy satisfies the backward recursion

\[
V_t(q,c^-)
=
\min_{c\in C}
\left[
q^\top\ell_c+\kappa(c^-,c)
+
\max_{q'\in\Gamma(q,c)}V_{t+1}(q',c)
\right].
\]

This is a finite dynamic-programming theorem, but it applies only when the current source-law state is actually observed before the code decision. If the source law is latent, the correct state is a belief or uncertainty set, not `q` itself.

## High-value unresolved distinctions

- open-loop robustness versus feedback value;
- source law observed before or after encoding;
- codebook update communicated to decoders or preshared;
- switching cost paid in bits, delay, energy, synchronization risk, or an abstract scalar;
- oblivious versus code-reactive source transitions;
- stochastic drift versus adversarial bounded drift;
- fixed-time statistical confidence versus anytime-valid filtering;
- dynamic absolute cost versus dynamic regret against a clairvoyant sequence;
- one decoder versus a network whose nodes receive code updates at different times.

Any later implementation should preserve these distinctions in its type system and claim ledger.
