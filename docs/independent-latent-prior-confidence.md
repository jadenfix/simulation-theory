# Confidence calibration from independent latent-model draws

## Scope

This lane estimates a categorical mixing law only under a specific hierarchical sampling design:

\[
M_1,\ldots,M_N\overset{iid}{\sim}\pi.
\]

Each count is one independent latent-model draw. Repeated lower-level observations generated after one persistent `M_u` do **not** create additional samples for this theorem.

## Exact second-moment bound

Let `p_hat` be the empirical law over `k` categories from `N` independent latent draws. Coordinate variances give

\[
E\|\hat p-p\|_2^2
=\frac{1-\sum_jp_j^2}{N}
\le\frac{k-1}{kN}.
\]

By Cauchy-Schwarz,

\[
\|v\|_1^2\le k\|v\|_2^2.
\]

Since

\[
TV(\hat p,p)=\frac12\|\hat p-p\|_1,
\]

we obtain

\[
\boxed{
E\,TV(\hat p,p)^2\le\frac{k-1}{4N}.
}
\]

Markov's inequality therefore gives

\[
\boxed{
P\{TV(\hat p,p)\ge\rho\}
\le
\frac{k-1}{4N\rho^2}.
}
\]

For target failure probability `alpha`, it is sufficient that

\[
\boxed{
\rho^2\ge\frac{k-1}{4N\alpha}.
}
\]

This bound is deliberately conservative. Its advantage here is that the derivation is elementary and the certificate can remain exact rational throughout.

## Exact outward rational rounding

The ideal radius generally contains a square root. The implementation chooses a declared denominator `D` and returns the smallest grid value

\[
\rho_D=\frac mD
\]

satisfying

\[
\rho_D^2\ge\frac{k-1}{4N\alpha}.
\]

The integer `m` is found by exact integer arithmetic. No floating approximation is needed to validate the coverage inequality.

If the required radius exceeds one, the certificate returns the full-simplex radius `1`. This is not a failure: it correctly records that the available sample is too weak for a nontrivial TV guarantee under this conservative bound.

## Composition with Bayesian experiment value

The preceding prior-robustness lane proves

\[
|V_p(S)-V_q(S)|\le TV(p,q)
\]

and two-Lipschitz marginal-gain sensitivity. Combining those deterministic theorems with the confidence event gives, with probability at least `1-alpha` under the declared iid latent-draw sampling model,

\[
V_p(S)\in[V_{\hat p}(S)-\rho_D,V_{\hat p}(S)+\rho_D]
\]

and

\[
G_p(S\to T)\in[G_{\hat p}(S\to T)-2\rho_D,G_{\hat p}(S\to T)+2\rho_D],
\]

with truncation to feasible loss ranges.

Likewise, nominal experiment-value rankings separated by more than `2 rho_D` and marginal-gain rankings separated by more than `4 rho_D` are certified throughout the confidence ball.

## Effective sample size is hierarchical

This point is essential. If one latent model is drawn once and then observed `T` times, `T` is not the `N` in the theorem above. The persistent-latent evidence lane proves the same distinction at the likelihood-ratio level.

For mixing-weight estimation, sample size increases when there are additional independent latent draws—e.g. independent units generated by the hierarchy—not merely because one unit was observed for longer.

## Nonclaims

- The theorem assumes latent model labels are observed for each independent unit. If labels are themselves inferred noisily, another layer is required.
- IID latent draws and stationarity are assumptions, not conclusions from the counts.
- The second-moment/Markov radius is conservative and is not claimed optimal.
- The confidence guarantee is fixed-sample; it is not anytime-valid under optional stopping.
- None of these statistical guarantees is evidence for simulation.
