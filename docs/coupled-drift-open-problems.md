# Coupled-drift open problems

1. Characterize necessary and sufficient conditions for the marginal relaxation
   to be tight beyond the sufficient common-ordering condition.
2. Derive a network-flow formulation of the finite-TV path support function that
   yields scalable exact dual receipts.
3. Characterize the codebook-sequence problem as a shortest path or dynamic
   program without enumerating all \(K^T\) sequences.
4. Quantify support-size and symmetry reductions for exchangeable codebooks.
5. Add observation-based causal policies and prove a belief-state sufficiency
   theorem under a declared hidden-mode model.
6. Separate value of information, value of reconfiguration, and value of
   clairvoyance in exact finite examples.
7. Study nonrectangular path ambiguity and dynamic inconsistency.
8. Extend the transition geometry to KL, Hellinger, chi-square, Wasserstein, and
   quantum trace distance with certified bounds.
9. Combine source drift with noisy communication channels and queueing delay
   without conflating source, channel, and network coding.
10. Define dynamic predictive equivalence for intervention-contingent reachable
    transcript laws and derive state-minimization theorems.
