# Coupled-drift review questions

A reviewer should be able to answer each question from the code and derivations.

1. Why is one event from each complement pair sufficient for exact finite TV?
2. How is the final simplex coordinate eliminated at each time step?
3. Why is the path polytope bounded and nonempty for a valid initial law and
   budgets in `[0,1]`?
4. Which configured cap certifies complete primal vertex enumeration?
5. How is the objective constant changed by simplex-coordinate elimination?
6. What independently verifies the maximizing vertex?
7. Which equations make the dual receipt replayable?
8. Why is the independent marginal calculation only an upper bound?
9. Under what sufficient condition does the marginal bound become tight?
10. Which explicit instance proves the relaxation can be strict?
11. Why is componentwise code-length dominance safe for every source law?
12. When is the code sequence selected relative to the source path?
13. What exact object is charged a switching cost?
14. Which example proves a changing sequence can beat every static code?
15. Why is the exact threshold `1/6` rather than a floating estimate?
16. Which information would an adaptive policy receive in the proposed next
    lane?
17. Which results are theorem, model result, and finite check?
18. Which claims remain internal decision-theoretic statements rather than
    parent-substrate resource claims?
