# Stabilizer-code distance and logical predictive locality

## Scope

The previous graph-state construction showed that exponentially many relational
labels can share every one- and two-qubit marginal while weight-three
stabilizer observables reveal the labels. Graph states, however, have a
one-dimensional stabilizer eigenspace: they encode no unknown logical quantum
state.

This note moves to genuine stabilizer **codes**. The central question is:

> When does a whole family of encoded states induce exactly the same laws for
> every observable below a declared physical locality, while higher-weight
> logical observables still distinguish the encoded information?

The answer is controlled by quantum code distance. This is more precise than
counting Hilbert-space dimension and stronger than checking only selected local
marginals.

All results concern internal predictive laws under declared physical Pauli and
logical-query interfaces. They do not imply a parent computer uses the same
representation or amount of hardware, and they are not evidence for simulation.

---

## 1. Binary symplectic representation

Ignoring an overall phase, an \(n\)-qubit Pauli can be represented by

\[
P(x,z)=X^xZ^z,
\qquad
x,z\in\mathbb F_2^n.
\]

At coordinate \(i\):

- \((x_i,z_i)=(0,0)\) represents \(I\);
- \((1,0)\) represents \(X\);
- \((0,1)\) represents \(Z\);
- \((1,1)\) represents \(Y\), up to the conventional phase.

The physical weight is

\[
\operatorname{wt}(x,z)
=|\operatorname{supp}(x\lor z)|.
\]

Two Paulis commute exactly when their symplectic inner product vanishes:

\[
\boxed{
\langle(x,z),(x',z')\rangle_s
=x\cdot z'+z\cdot x'
=0\pmod2.
}
\]

The implementation encodes \((x,z)\) as one integer, performs exact GF(2)
rank and span calculations, and checks commutation without floating-point
linear algebra.

## 2. Stabilizer code parameters

Let \(S\) be generated by \(r\) independent commuting Hermitian Paulis
\(g_1,\ldots,g_r\), with no \(-I\) in the group. The codespace is the joint
\(+1\) eigenspace

\[
\mathcal C
=\{ |\psi\rangle:g_j|\psi\rangle=|\psi\rangle\ \forall j\}.
\]

Each independent commuting generator halves the dimension, so

\[
\dim\mathcal C
=2^{n-r}.
\]

Define

\[
\boxed{k=n-r.}
\]

The code encodes \(k\) logical qubits.

Let \(N(S)\) be the Pauli normalizer, equivalently the set of Paulis commuting
with every stabilizer generator. Elements of \(S\) act as scalars on the
codespace. Elements of \(N(S)\setminus S\) act nontrivially on logical degrees
of freedom.

The quantum distance is

\[
\boxed{
d
=
\min_{P\in N(S)\setminus S}
\operatorname{wt}(P).
}
\]

In binary form, \(S\) is a linear subspace of dimension \(r\), and \(N(S)\)
is its symplectic orthogonal subspace of dimension \(2n-r\). Therefore

\[
|N(S)/S|
=2^{2n-r-r}
=2^{2k}
=4^k.
\]

The code enumerates the normalizer for bounded \(n\), quotients it by the
stabilizer span, and chooses a minimum-weight leader for every logical Pauli
coset.

### A distinction that is often blurred

For a stabilizer **state** with \(k=0\), the minimum nonidentity stabilizer
weight controls which reduced states are maximally mixed. For a stabilizer
**code** with \(k>0\), the operational code distance is instead the minimum
weight in \(N(S)\setminus S\).

These quantities are not interchangeable:

- minimum stabilizer weight asks when a stabilizer correlation first appears;
- code distance asks when an operator can act nontrivially on logical
  information.

## 3. Projected Pauli trichotomy

Let \(\Pi\) be the projector onto the codespace.

Take any physical Pauli \(P\).

### Case 1: detectable Pauli

If \(P\) anticommutes with some stabilizer \(g\), then

\[
\Pi P\Pi
=
\Pi gPg\Pi
=-\Pi P\Pi,
\]

because \(g\Pi=\Pi g=\Pi\). Hence

\[
\boxed{\Pi P\Pi=0.}
\]

### Case 2: stabilizer Pauli

If \(P\in S\) up to phase, it acts as a scalar on the codespace:

\[
\boxed{\Pi P\Pi=\lambda_P\Pi.}
\]

### Case 3: logical Pauli

If \(P\in N(S)\setminus S\), then it preserves the codespace but is not scalar.
It acts as a nontrivial logical Pauli.

Thus every physical Pauli has one of three restrictions:

\[
\boxed{
\text{projected-zero},\quad
\text{scalar},\quad
\text{logical}.
}
\]

The repository implements and tests this trichotomy directly.

## 4. Code distance implies complete local indistinguishability

Assume \(P\) has weight below code distance:

\[
\operatorname{wt}(P)<d.
\]

It cannot be in \(N(S)\setminus S\) by definition of \(d\). Therefore it is
either detectable or scalar, and

\[
\boxed{
\Pi P\Pi=c_P\Pi
\qquad
\text{for every }\operatorname{wt}(P)<d.
}
\]

Now let \(A\) be any subset of fewer than \(d\) physical qubits, and let
\(O_A\) be an arbitrary operator supported on \(A\). Expand it in the Pauli
basis:

\[
O_A
=
\sum_{P:\operatorname{supp}(P)\subseteq A}
\alpha_PP.
\]

Every term has weight below \(d\), so

\[
\Pi O_A\Pi
=
\left(\sum_P\alpha_Pc_P\right)\Pi
=c(O_A)\Pi.
\]

Hence for any normalized code states \(|\psi\rangle,|\phi\rangle\),

\[
\langle\psi|O_A|\psi\rangle
=
\langle\phi|O_A|\phi\rangle.
\]

Because equality holds for every operator on \(A\), their reduced density
matrices are identical:

\[
\boxed{
\rho_A^{\psi}
=
\rho_A^{\phi}
\qquad
\forall |A|<d.
}
\]

This is stronger than saying a few local observables happen to agree. **Every
possible measurement** on fewer than \(d\) physical qubits has the same law for
every encoded state.

The same calculation gives the off-diagonal quantum error-correction condition:
for orthogonal code states,

\[
\langle\psi|O_A|\phi\rangle=0
\]

whenever \(|A|<d\).

## 5. Erasure interpretation

If a subset \(A\) contains fewer than \(d\) qubits, the environment holding
\(A\) receives no information about the logical state because all logical
states have the same reduced density matrix on \(A\).

Equivalently, erasure of \(A\) is correctable: the complement contains all
logical information needed to recover the encoded state.

This interpretation is useful for the simulation question. The logical state
need not be represented in any one small local region. It is constrained by a
relational structure spread across the code block. An online generator that
only matches every sub-\(d\) local marginal can still fail every logical
cross-check.

## 6. Quantum Singleton bound from two correctable erasures

A finite \([[n,k,d]]\) quantum code obeys

\[
\boxed{n-k\ge2(d-1).}
\]

A compact entropy proof clarifies the origin of the factor two.

Encode one half of a maximally entangled state of \(k\) qubits, keeping the
reference system \(R\). Partition the \(n\) physical qubits into disjoint sets
\(A,B,C\), with

\[
|A|=|B|=d-1,
\qquad
|C|=n-2(d-1).
\]

Both erasures \(A\) and \(B\) are correctable. Correctability implies the erased
region is decoupled from the reference:

\[
I(R:A)=0,
\qquad
I(R:B)=0.
\]

The global state on \(RABC\) is pure. From \(I(R:A)=0\),

\[
S(BC)=S(RA)=S(R)+S(A).
\]

Subadditivity gives

\[
S(R)+S(A)
\le S(B)+S(C).
\]

Similarly,

\[
S(R)+S(B)
\le S(A)+S(C).
\]

Adding cancels \(S(A)+S(B)\):

\[
2S(R)
\le2S(C).
\]

The reference entropy is \(S(R)=k\), while \(S(C)\le|C|\), so

\[
k
\le
n-2(d-1).
\]

Rearranging proves the bound.

A code saturating the bound is quantum maximum-distance separable in this
finite sense.

## 7. The five-qubit perfect code

The repository includes the stabilizer generators

\[
\begin{aligned}
g_1&=XZZXI,\\
g_2&=IXZZX,\\
g_3&=XIXZZ,\\
g_4&=ZXIXZ.
\end{aligned}
\]

They commute and are independent, so

\[
r=4,
\qquad
k=5-4=1.
\]

Exact normalizer enumeration finds

\[
\boxed{d=3.}
\]

The nontrivial logical Pauli cosets each have a weight-three representative.
The familiar representatives

\[
\overline X=XXXXX,
\qquad
\overline Z=ZZZZZ
\]

are valid but not minimum weight; multiplying by stabilizers reduces their
physical support.

The code parameters are therefore

\[
\boxed{[[5,1,3]].}
\]

The Singleton slack is

\[
5-1-2(3-1)=0,
\]

so the code saturates the quantum Singleton bound.

### Independent state-vector check

The implementation does not rely only on binary enumeration. It also constructs
logical \(\overline Z\) eigenstates by applying commuting projectors

\[
\prod_{j=1}^{4}(I+g_j)
(I\pm\overline Z)
\]

to computational basis seeds and normalizing the first nonzero result.

It verifies:

- every stabilizer expectation is \(+1\);
- the two logical codewords are orthogonal;
- \(\overline Z\) has eigenvalues \(+1\) and \(-1\);
- \(\overline X\) maps one logical basis state to the other;
- all one- and two-qubit reductions agree for logical
  \(|0\rangle,|1\rangle,|+\rangle,|+i\rangle\);
- a minimum weight-three logical representative produces a distinguishable
  three-qubit reduced law.

The binary and state-vector routes are independent bounded checks of the same
locality statement.

## 8. Why the three-qubit repetition code is not a [[3,1,3]] quantum code

Consider stabilizers

\[
ZZI,
\qquad
IZZ.
\]

These define the span of \(|000\rangle\) and \(|111\rangle\), often called the
three-qubit bit-flip repetition code.

It detects any one-qubit \(X\) error because \(XII\), \(IXI\), and \(IIX\)
anticommute with a stabilizer. But

\[
ZII
\]

commutes with both stabilizers, lies outside their span, and acts as logical
\(\overline Z\). Its weight is one. Therefore

\[
\boxed{d=1}
\]

as a full quantum code.

This is an important conceptual warning:

> Protection against one selected error type is not the same as quantum code
> distance.

A simulation argument that says “this redundancy protects one bit against one
flip” has not established local indistinguishability against arbitrary physical
measurements.

## 9. Encoded logical predictive geometry

Take \(m\) independent blocks of an \([[n,k,d]]\) code and restrict to a
logical computational basis indexed by

\[
z\in\{0,1\}^{mk}.
\]

Suppose a future query selects one logical \(Z\) coordinate and records its
deterministic eigenvalue. With query weights \(w_i\), the exact predictive law
satisfies

\[
\boxed{
\operatorname{TV}(P_z,P_u)
=
\sum_iw_i\mathbf1\{z_i\ne u_i\}.
}
\]

Under uniform logical-coordinate queries, this is normalized Hamming distance.
Under worst-coordinate queries, every distinct pair has distance one.

For approximation tolerance \(\epsilon<1/2\), no two logical labels can share
one worst-query predictive state. Therefore

\[
\boxed{
\text{memory}\ge mk\text{ bits}.
}
\]

The lower bound is tight for the declared logical basis: retaining the logical
label itself is sufficient.

For \(m\) five-qubit blocks, this gives:

- \(5m\) physical qubits;
- \(m\) encoded predictive bits;
- every physical measurement on fewer than three qubits is independent of the
  encoded state;
- weight-three logical queries can recover the encoded coordinates.

This separates three scales that informal discussions often collapse:

1. physical system size \(5m\);
2. local blindness threshold \(d-1=2\);
3. logical predictive information \(m\) bits.

## 10. What this contributes to an online-rendering analysis

The theorem does **not** show that an encoded state must be stored as a dense
\(2^n\)-component vector. Stabilizer states and codes often admit compact
algebraic descriptions.

It shows something narrower and operational:

- a renderer that exposes only sub-distance local observations may postpone
  revealing the logical state;
- it cannot discard the logical predictive information if later allowed
  logical observables must be answered consistently;
- low-order local agreement is therefore not sufficient evidence that two
  internal histories can be merged;
- the relevant lower bound comes from the number of distinct future laws, not
  from raw Hilbert-space dimension.

For the five-qubit block family, one bit per block is necessary under the
logical-query interface. A stabilizer tableau can meet that order of storage,
showing why lower and upper bounds should be developed together.

## Nonclaims

- Quantum code distance is not evidence for simulation.
- The code-space dimension is not automatically a parent-hardware memory cost.
- The theorem concerns physical subsets with fewer than \(d\) qubits; an
  adaptive protocol aggregating several local measurements may implement a
  higher-weight logical observable.
- State-vector projection is used only as a bounded independent checker, not as
  the asserted optimal representation.
- The five-qubit code is one finite example and does not establish a scalable
  family with growing distance and rate.
- The quantum Singleton bound constrains code parameters under ordinary quantum
  information assumptions; it does not constrain unknown parent physics.
- The logical-label predictive result uses declared logical computational-basis
  states and logical-Z queries, not arbitrary continuous logical states.
