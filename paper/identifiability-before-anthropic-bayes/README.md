# Identifiability Before Anthropic Bayes — reproducible paper artifact

Author: **Jaden Figgs**, Tempera — `Jaden@Tempera.dev`

This directory is the frozen source bundle for the paper. The paper is intentionally a foundations/identifiability result, not a claim that reality is simulated.

## Contents

- `paper.tex` — manuscript source.
- `references.bib` — bibliography. DOI-bearing journal metadata was cross-checked against publisher, institutional-repository, or journal-index records during drafting.
- `claims.json` — theorem-by-theorem scope, assumptions, novelty status, and nonclaims.
- `reproduce.py` — Python-standard-library exact-rational reproduction of every numerical example used in the manuscript.
- `receipt.json` — deterministic output generated by `reproduce.py`.

## Reproduce

```bash
cd paper/identifiability-before-anthropic-bayes
python reproduce.py
```

The script must exit zero and regenerate `receipt.json` byte-for-byte after the embedded hash field is recomputed from the canonical payload.

If a TeX toolchain is installed:

```bash
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
bibtex paper
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
```

## Audit policy

1. Theorem proofs are written in the manuscript rather than delegated to code.
2. Code checks finite examples and boundary witnesses; it does not promote a finite check into a theorem.
3. `claims.json` distinguishes classical consequences, elementary structural lemmas, constructive witnesses, and scoped theorem claims.
4. The two-view theorem is explicitly a result **inside the declared row-stochastic gauge orbit**, not a global two-view latent-class identifiability theorem.
5. The persistent-latent likelihood-ratio ceiling requires denominator support/absolute continuity on the realized transcript.
6. The refinement-additivity theorem is elementary; the proposed contribution is its role inside the integrated simulation/anthropic identifiability hierarchy.
7. Before journal submission, literature provenance should be independently rechecked by a human and at least one external expert should attempt to falsify the central argument.
